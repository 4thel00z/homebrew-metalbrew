# homebrew-metalbrew

Homebrew tap for [metalbrew](https://github.com/4thel00z/metalbrew) — a
Homebrew-compatible, Zig-based bottle package manager for Apple Silicon.

## Install

```sh
brew install 4thel00z/metalbrew/metalbrew
```

or, equivalently:

```sh
brew tap 4thel00z/metalbrew
brew install metalbrew
```

The formula builds from source with Zig (a build-time dependency). metalbrew
targets **macOS on Apple Silicon (arm64) only**.

## Updating

```sh
brew update
brew upgrade metalbrew
```
